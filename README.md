# FlyRank Backend Track - Assignment A1: To-Do CRUD API

A simple, in-memory Express CRUD API built as part of the FlyRank AI Backend Internship program.

## How to Run

1. Clone this repository:
   ```bash
   git clone <YOUR_GITHUB_REPO_URL>
   cd flyrank-w2-a1

```

2. Install dependencies:
```bash
npm install

```


3. Start the server:
```bash
node index.js

```


4. Access Swagger UI docs at: `http://localhost:3000/docs`
